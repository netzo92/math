# Math working rules

Start with README.md, then read the note for the track you are changing. Keep each iteration scoped to one explicit mathematical question.

For complexity claims, state the computational model and distinguish operation counts, asymptotic results, and elapsed time. Record benchmark environment and rerun correctness checks before comparing speed.

For Zcash topics, cite the current protocol or implementation source for protocol facts. Mark toy models clearly. Do not call an experiment protocol-compatible without checking it against authoritative specifications and vectors. Never put wallet keys, seeds, or real private data in this public repository.

End a completed iteration by updating its note: result, evidence scope, remaining uncertainty, and one next question.
